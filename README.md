# Project Progmeth

## Project Structure

| Path | Description |
|------|-------------|
| `src/main/java/` | Main source code |
| `src/test/java/` | Unit tests (JUnit 5) |
| `src/main/resources/` | Images, sounds, maps, and fonts |
| `build/docs/javadoc/index.html` | **Javadoc HTML documentation** |
| `build.gradle` | Gradle build configuration |

## Javadoc

Full API documentation (including private members) is available at:

**[build/docs/javadoc/index.html](build/docs/javadoc/index.html)**

To regenerate:
```bash
./gradlew javadoc
```

## How to Run

```bash
./gradlew run
```

## How to Test
